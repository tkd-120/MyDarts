# MyDarts MVP Specification

この文書は、MyDarts の MVP（v0.x）で目指す仕様を整理したものです。スマホ縦画面前提のシンプルな UI で、カウントアップ・01-301・クリケットを 1〜4 人で楽しめることをゴールにします。

## 1. アプリ概要
- アプリ名: **MyDarts**
- 提供機能: ダーツのスコア管理（カウントアップ / 01-301 / クリケット）
- 想定利用: 自宅でのマイダーツ練習・スコア計算
- プラットフォーム: スマホブラウザ（縦画面、PWA 想定でも可）
- プレイヤー数: 1〜4 人

## 2. 対応モード
起動後のプレイヤー設定画面で以下から選択:
1. **COUNT UP**
2. **ZERO ONE 301**（シングルアウト、最大 10 ラウンド）
3. **CRICKET**（クリケット、最大 15 ラウンド）

## 3. 共通仕様
### 3.1 プレイヤー
- プレイヤー数: 1〜4 人
- プレイヤー名: テキスト入力。未入力時は `PLAYER1`/`PLAYER2`… を自動付与
- 手番順: 登録順固定（P1 → P2 → … → PN → P1 …）

### 3.2 入力 UI（共通）
- 数字ボタン: **1〜20**
- 種別ボタン: **S / D / T**
- BULL ボタン: **OB（25） / IB（50）**
- **MISS ボタン**: 0 点で 1 投消費（ミス入力用）
- スコア計算: `S=number`, `D=number×2`, `T=number×3`, `OB=25`, `IB=50`, `MISS=0`
- 入力フロー: 種別を選択（デフォルト S）→ 数字または BULL/MISS を押す → その 1 投を即時確定

### 3.3 ラウンド構造
- 1 ラウンド = 各プレイヤー 3 投
- 進行: Round X で P1 が 3 投 → P2 が 3 投 → … → PN が 3 投 → 次のラウンドへ
- 最大ラウンド数はモードごとに異なる（後述）

### 3.4 画面構成
- **プレイ画面**: 上部にプレイヤー一覧・スコア情報（モード別表示）、中央に現在プレイヤーの今ラウンド 3 投と小計、下部に入力 UI（数字＋S/D/T/OB/IB/MISS）と UNDO
- **結果画面**: モードに合わせた最終スコア表示と順位/勝者表示。「もう一度プレイ」「新しいゲーム」ボタンを提供

### 3.5 UNDO（取り消し）
- UNDO ボタンで直近 1 投を取り消し
- 連打で過去にさかのぼれる（制限なし）
- ゲーム終了後 (`finished`) でも実行可能。取り消した投が勝敗を変える場合はステータスを巻き戻す

## 4. モード別仕様
### 4.1 COUNT UP
- 初期スコア: **0 点**
- ラウンド数: **最大 8 ラウンド**（各ラウンド 3 投）
- スコア: 各投のスコアを加点。`totalScore` は累計、`roundScore` はそのラウンドの加点合計
- 終了: Round8 の最後の投が終わったら終了。`totalScore` の高い順で結果表示

### 4.2 ZERO ONE 301
- 開始スコア: **301**
- ラウンド数: **最大 10 ラウンド**（各ラウンド 3 投）
- ルール: シングルアウト（0 ちょうどなら何で上がってもよい）
- スコア: `remainingScore = remainingScore - score` で減点。0 以上のみ有効
- **バースト (BUST)**: `remainingScore - score < 0` の場合、そのターンの得点は全て無効になり、ターン開始時の残りスコアに戻して即座に次プレイヤーへ
- **終了条件**:
  - だれかが 0 にした瞬間に即終了し勝者決定
  - 10 ラウンドを投げ切っても上がりがない場合、`remainingScore` が最小のプレイヤーを勝者（同点は引き分け）

### 4.3 CRICKET（15 ラウンド制）
- 対象ナンバー: **15 / 16 / 17 / 18 / 19 / 20 / BULL**（1〜14 は無効）
- マーク数: プレイヤーごとに各ナンバーのマークを保持。`S=1`, `D=2`, `T=3`, `OB=1`, `IB=2`
- クローズ: 3 マーク以上でそのプレイヤーにとってクローズ
- 得点ルール:
  - 自分がクローズ済み & 他プレイヤーに未クローズがいる場合のみ「余剰マーク」が得点化
  - 15〜20: `number × 余剰マーク`, BULL: `25 × 余剰マーク`
  - 条件を満たさない場合は得点なしでマークだけ増加
- 勝利条件:
  - 1 投ごとに「全ナンバー 3 マーク以上」かつ「自分の cricketScore が全員以上」を満たした瞬間に勝利・即終了
  - 15 ラウンド終了まで勝者なしの場合:
    1. 全ナンバーをクローズしたプレイヤーがいれば、その中で cricketScore 最大が勝者
    2. 誰も全クローズしていなければ、全プレイヤーの中で cricketScore 最大が勝者
    3. 同点は引き分け扱い

## 5. 非機能要件
- UI: スマホ縦画面・片手操作を優先。現在のモード / ラウンド / 手番が即分かること
- デザイン: シンプル・フラット。不要なアニメーションや装飾は省く
- パフォーマンス: 投入後は即時反映。遅延を感じさせない
- 安定性: モードを跨いでも UNDO ロジックが破綻しないよう、スナップショット型の状態管理を推奨

## 6. 利用フロー（概要）
1. プレイヤー設定: 人数と名前を入力し、モードを選択してゲーム開始
2. プレイ: 下部の入力 UI で 1 投ずつ記録。UNDO で誤入力を巻き戻し可能
3. 結果表示: 終了条件を満たすと結果画面に遷移。「もう一度プレイ」で同設定リスタート、「新しいゲーム」で設定画面へ戻る

この仕様は「開発用の実装指針」としても、そのまま関係者共有用の説明資料としても利用できます。
